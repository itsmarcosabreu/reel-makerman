# fx-etiqueta

Texto curto sobre o rosto em tela cheia (`tema: "full"`, `rosto: "full"`). Ótimo para um "gancho" ou virada.

```json
{ "tipo": "etiqueta", "texto": "quem decide", "de": 32.27, "ate": 36.45 }
```

- Até 3 palavras. Troca de etiqueta: dê `ate` igual ao `de` da próxima.
- Som automático: `fx-etiqueta`.
